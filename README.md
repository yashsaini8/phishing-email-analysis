# Phishing Email Analysis

## Overview

This project presents a defensive analysis of a simulated phishing email.

The objective is to identify indicators commonly associated with phishing attacks and document the analysis process used to evaluate a suspicious email.

## Objectives

- Identify social engineering techniques
- Analyze suspicious sender information
- Examine email headers
- Identify suspicious URLs
- Document indicators of compromise
- Explain recommended defensive actions

## Disclaimer

This project uses a simulated/sanitized phishing sample for educational and defensive cybersecurity purposes.

No real credentials or sensitive personal information are included.

The detailed analysis is available in phishing-analysis.md.
